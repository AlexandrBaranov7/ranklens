# Безопасность

## Поддерживаемые версии

До выхода `1.0.0` исправления выпускаются только для последней версии.

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте
[private vulnerability reporting](https://github.com/AlexandrBaranov7/ranklens/security/advisories/new).

## Известные риски использования

- **Загрузка моделей.** Модели scikit-learn сохраняются через pickle, а загрузка
  pickle исполняет произвольный код. Загружайте в `ranklens explain` только модели
  из доверенных источников.
- **Отчёты.** HTML-отчёт встраивает значения query_id и doc_id из входных данных;
  они экранируются, но открывать отчёты по недоверенным данным стоит с той же
  осторожностью, что и любой HTML.

## 2026-09-16 — неделя 4: ErrorCollector, форматы, iter_run

**Ассистент:** Claude Code (Claude Opus 5), агентный режим.

**Предложено ассистентом:** `ErrorCollector` с примерами, ограниченными
**на каждый тип** ошибки (а не первые N вообще — иначе редкий тип ошибки
не попадёт в сводку за частым); отдельные `UngroupedInputError` и
`MissingColumnError` вместо переиспользования `UnsortedInputError`/`MalformedRowError`
с неточным текстом; иерархия предупреждений для non-strict режима.
Форматы: TREC сверх плана, разделение на слой форматов и слой схемы (D-012).
`iter_run`: два режима проверки порядка (D-013, закрывает Q-1); замер
памяти показал ~190 байт на запрос в режиме `grouped` — записано как цена
решения, а тест на память проверен мутацией (reader, копящий выдачи, его роняет).
По ревью PR #3: интерфейс коллектора сужен до `record`/`snapshot` (D-015).

**Не устроило / переписано вручную:** избыточный интерфейс ErrorCollector'а, класс сужен. Отсутствие популярных форматов pq, feather, arrow

**Проверено самостоятельно:** проведено ревью кода.

## 2026-09-18 — неделя 5: реестр метрик

**Ассистент:** Claude Code (Claude Opus 5), агентный режим.

**Предложено ассистентом:** убрать `name` из протокола `Metric` — тогда функция
действительно является метрикой без обёрток (проверено пробным запуском mypy);
реестр фабрик и синтаксис ir_measures (D-017). Значения по умолчанию как в trec_eval
и 0 для запросов без релевантных документов — выбор автора из двух предложенных вариантов.
Метрики: первая версия кэшировала функцию gain во frozen-классе через
`object.__setattr__` — упрощено до проверки в `__post_init__`. Тест на swap-монотонность
сначала отбрасывал слишком много примеров (health check Hypothesis) — переписан так,
чтобы каждая пара позиций давала проверку.
`evaluate` и CLI: код выхода 3 для ошибок данных вместо 2 из плана — код 2 занят
argparse (D-019); значения на игрушечных данных сверены с ручным расчётом.

**Не устроило / переписано вручную:** в целом ок, не совсем сразу понятно о потребителях registry.

**Проверено самостоятельно:** ревью PR.

## 2026-09-19 — неделя 6: ERR, RBP, RBO

**Ассистент:** Claude Code (Claude Opus 5), агентный режим.

**Предложено ассистентом:** шкала `max_rel` как параметр метрики, а не максимум по запросу;
бинарный RBP по умолчанию и нормировка градуированного на шкалу (D-020, закрывает Q-5);

Порядок trec_eval при равных score установлен экспериментом с pytrec_eval, а не по памяти;
синтетический эталон вместо публичных qrels; чувствительность golden-теста проверена
мутацией (D-022).
Векторизация: одна матрица релевантностей на пачку для всех метрик, сторонние метрики
без `batch` считаются по-старому; эквивалентность проверена Hypothesis, замер — 7.5x (D-023).
Плагины: ленивая загрузка, сломанный плагин пропускается с предупреждением, встроенные
имена не перекрываются; сквозной тест с настоящим пакетом во временной папке (D-024).

**Не устроило / переписано вручную:** различность архитектур метрик, перепроверить или переписать под одним ABC Metric.

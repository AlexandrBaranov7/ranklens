## 2026-09-25 — неделя 7: paired bootstrap

**Ассистент:** Claude Code (Claude Opus 5), агентный режим.

**Предложено ассистентом:** ресемплинг запросов (не строк) с обоснованием в D-025;
чанки по памяти с проверкой, что numpy даёт ту же последовательность при любом
разбиении — поэтому результат воспроизводим независимо от размера чанка;
валидация покрытия на 1000 симуляций прямо в обычном наборе тестов (укладывается в секунду).
Тест «интервал не исключает ноль» сначала был написан на данных со средним 0.25 —
ожидание было неверным, поправлен тест, а не утверждение.
Перестановочный тест: `(b+1)/(m+1)`, равномерность проверяется долей отвержений,
а не KS (p-value дискретен); два независимых потока случайности из одного seed (D-026).

**Не устроило / переписано вручную:** рейз ошибки при маленьком семпле - по сути исключительной ситуации не возникает, код отработает, однако цифры которые мы получим будут ненадёжными, поэтому предложен варнинг вместо ошибки.

**Проверено самостоятельно:** весь стек PR'ов.

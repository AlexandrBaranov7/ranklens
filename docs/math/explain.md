# Объяснение пар

Почему модель поставила документ B выше документа A? `ranklens.explain.pairwise`
раскладывает разницу скоров $s(x^B) - s(x^A)$ по признакам.

## Путь от A к B

Пойдём от признаков A к признакам B, заменяя по одному: каждому признаку припишем
изменение скора, которое вызвала его замена. Если признаки не взаимодействуют
(скор — сумма функций от отдельных признаков), ответ не зависит от порядка. Если
взаимодействуют — зависит. Пример: $s = x_1 x_2$, $A = (0, 0)$, $B = (1, 1)$:
меняем сначала $x_1$ — скор не изменился, весь прирост достаётся $x_2$; меняем сначала
$x_2$ — наоборот.

## Значение Шепли

Честный ответ — среднее по всем порядкам. Для признака $i$ из $k$ и набора $S$ признаков,
уже взятых у B ($v(S)$ — скор точки, где признаки из $S$ взяты у B, остальные у A):

$$
\varphi_i = \sum_{S \subseteq \{1..k\} \setminus \{i\}}
\frac{|S|!\,(k - |S| - 1)!}{k!}\,\bigl(v(S \cup \{i\}) - v(S)\bigr).
$$

Свойства, которые проверяются тестами:

- **сумма вкладов равна разнице скоров:** $\sum_i \varphi_i = v(\text{все}) - v(\varnothing) = s(x^B) - s(x^A)$;
- **признак, который у A и B одинаков, получает 0;**
- **для линейной модели** $\varphi_i = w_i\,(x^B_i - x^A_i)$;
- **для $x_1 x_2$** признак получает $\tfrac12 (x^B_1 - x^A_1)(x^A_2 + x^B_2)$ — среднее двух порядков.

## Точно или по выборке

При $k \le 12$ перебираются все $2^k$ наборов: 4096 точек — один вызов модели.
Дальше $2^k$ растёт слишком быстро, и усредняются случайные порядки (`n_permutations`).
Каждый порядок — путь от A к B, поэтому и по выборке сумма вкладов равна разнице
скоров **точно**; от размера выборки зависит только то, как поделена эта разница.

```python exec="on" source="block" result="text"
import numpy as np

from ranklens.explain import CallableAdapter, pairwise

# скор: релевантность текста, умноженная на свежесть, плюс небольшой бонус за цену
model = CallableAdapter(lambda x: x[:, 0] * x[:, 1] + 0.1 * x[:, 2], ["bm25", "freshness", "price"])
a = [2.0, 0.2, 1.0]  # хороший текст, старый документ
b = [1.5, 0.9, 1.0]  # текст похуже, но свежий
result = pairwise(model, a, b)
print(f"s(A) = {result.score_a:.3f}, s(B) = {result.score_b:.3f}, разница {result.delta:+.3f}")
for name, contribution in result.ranked():
    print(f"  {name:10} {contribution:+.3f}")
```

B выше за счёт свежести; часть её вклада съедает более слабый текст. Цена у A и B
одинакова и не получает ничего.

## Ограничения

- Точки «наполовину A, наполовину B» могут быть нереалистичными (свежий документ
  с признаками старого): модель оценивается там, где не обучалась. Это общий недостаток
  интервенционного Шепли; на коррелированных признаках вклады размазываются —
  поэтому в неделю 11 появится группировка коррелированных признаков.
- Объясняется скор, а не позиция: большая разница скоров может не менять порядок.
  Вклад в метрику — списковое объяснение (неделя 11).

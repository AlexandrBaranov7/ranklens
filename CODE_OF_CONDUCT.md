# Кодекс поведения

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Коротко:

- уважительное общение, критика — к коду и решениям, а не к людям;
- без оскорблений, травли, дискриминации и публикации чужих личных данных;
- мейнтейнеры вправе удалять комментарии, коммиты и issue, нарушающие кодекс.

О нарушениях сообщайте мейнтейнеру через
[приватное сообщение на GitHub](https://github.com/AlexandrBaranov7) или
через private security advisory репозитория. Обращения рассматриваются
конфиденциально.
